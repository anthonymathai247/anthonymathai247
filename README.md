## Featured Work

### SHSAT Math Studio

An interactive math practice platform and companion product for my published SHSAT math book. The public showcase highlights the product, architecture, and launch metrics without exposing proprietary question-bank content.

- 296-page published math book
- 600-question book bank and 10 full-length exams
- Companion platform with 1,300+ original practice problems
- Diagnostics, timed tests, staged hints, mistake tracking, protected access, and progress reporting
- Built with JavaScript, Python content pipelines, Cloudflare Pages/Workers/D1, and a privacy-aware content delivery model

[View showcase](https://github.com/anthonymathai247/shsat-math-studio-showcase)
